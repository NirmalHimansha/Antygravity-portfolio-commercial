# Personal Portfolio Website

A stunning, fully responsive personal portfolio website built with HTML, CSS, and JavaScript. Features modern design aesthetics, smooth animations, and professional UI/UX.

## ✨ Features

- 🎨 **Modern Design**: Vibrant gradients, glassmorphism effects, and dark theme
- 📱 **Fully Responsive**: Works perfectly on desktop, tablet, and mobile devices
- 🎭 **Smooth Animations**: AOS library integration with custom CSS animations
- 🎯 **Interactive Elements**: Hover effects, 3D tilt cards, and dynamic typing
- 📧 **Contact Form**: Functional form with validation and success message
- 🚀 **Performance Optimized**: Fast loading and smooth scrolling

## 🏗️ Sections

1. **Hero** - Eye-catching introduction with animated background
2. **About** - Personal bio with statistics and professional image
3. **Skills** - Technology showcase with interactive cards
4. **Projects** - Portfolio gallery with hover effects
5. **Contact** - Contact form and social media links

## 🛠️ Technologies

- HTML5
- CSS3 (Grid, Flexbox, Custom Properties)
- JavaScript (ES6+)
- Google Fonts (Inter, Outfit)
- Font Awesome 6.4.0
- AOS 2.3.1 (Animate On Scroll)

## 🚀 Getting Started

1. Open `index.html` in your browser
2. Customize the content with your information
3. Replace images in the `images/` folder
4. Deploy to your preferred hosting platform

## 🎨 Customization

### Change Colors
Edit CSS variables in `style.css`:
```css
:root {
    --primary-hue: 250;      /* Purple */
    --secondary-hue: 320;    /* Pink */
    --accent-hue: 180;       /* Cyan */
}
```

### Update Content
- Edit text directly in `index.html`
- Replace images in `images/` folder
- Modify social links in the contact section
